# Recall v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A native macOS menu bar clipboard manager that saves every copy and pastes it back via a PasteNow-style panel.

**Architecture:** Swift Package with two targets. `RecallCore` (library) holds all logic that can be tested without UI: classification, the clip store, pasteboard read/write, shortcut validation, settings. `Recall` (executable) is the AppKit/SwiftUI shell: status item, panel, menus, settings window, hotkey, watcher timer, paster. A script bundles the executable into `Recall.app`, signs it with the user's existing **Apple Development** identity (stable signature so the Accessibility grant survives rebuilds) and installs it to `/Applications`.

**Tech Stack:** Swift 6.4, SwiftUI + AppKit, Carbon (hotkey), ServiceManagement (login item), CoreGraphics events (paste), Swift Testing (`import Testing`). No third-party dependencies.

**Spec:** `docs/design.md` (decisions cited as #n are in `docs/decisions.md`; mockup `docs/mockup.html` shows every screen).

## Global Constraints

- macOS 27, arm64; package `platforms: [.macOS("27.0")]`; if the toolchain rejects that string, use `.macOS(.v15)`.
- Bundle id `app.recall.Recall`; name **Recall**; `LSUIElement = true` (no Dock icon).
- Storage only under `~/Library/Application Support/Recall`; no networking code at all (#9).
- History limit default **200**, range **10–5000**; pinned clips never trimmed or cleared (#15–#17, #33).
- Skip clips whose formats total **> 25 MB** (25 × 1024 × 1024 bytes) (#14).
- Never save pasteboards containing `org.nspasteboard.ConcealedType`, `org.nspasteboard.TransientType` or `org.nspasteboard.AutoGeneratedType` (#8).
- Recall's own writes carry marker type `app.recall.own` and are ignored by the watcher.
- Default shortcut ⌘⇧V = Carbon keyCode `9`, modifiers `cmdKey | shiftKey`; a shortcut must include ⌘, ⌃ or ⌥ (#27, #29).
- Monitoring interval options `0.25, 0.5, 1, 2` seconds, default `0.5`.
- Icons: `assets/AppIcon.icns`, `assets/MenuBarIcon.png`, `assets/MenuBarIcon@2x.png` (template).
- Sign with `codesign --sign "Apple Development"`; never ad-hoc for the installed app.

## Review Focus

1. **Corrupt or unreadable `index.json`** → app still launches with empty history, and the bad file is renamed to `index.json.corrupt` instead of being overwritten (test in Task 2).
2. **A clip whose data files were deleted from disk** → pasting it shows "Clip data missing" and removes the clip, no crash (test in Task 2: `data(for:)` returns nil).
3. **Pasting a Finder-file clip whose file no longer exists** → file URL still written; Finder handles it; Recall must not crash (covered by Task 3 writer test with a non-existent path).
4. **Two copies faster than the poll interval** → only the latest is saved; accepted, but the watcher must never save the same `changeCount` twice (test in Task 4).
5. **Panel opened on a second display / full-screen app** → panel appears on the screen that has the mouse, under that screen's menu bar (manual check in Task 9).

### Task 2: Clip model + ClipStore with persistence

**Files:**
- Create: `Sources/RecallCore/Clip.swift`, `Sources/RecallCore/ClipStore.swift`, `Tests/RecallCoreTests/ClipStoreTests.swift`

**Interfaces:**
- Consumes: `ClipKind`
- Produces:
```swift
public enum Tab { case history, pinned }
public struct ClipDraft { public var formats: [String: Data]; public var plainText: String?; public var fileURLs: [URL]
                          public var kind: ClipKind; public var contentHash: String; public var sourceBundleID: String? }
public struct Clip: Codable, Identifiable, Equatable { public let id: UUID; public var kind: ClipKind; public var preview: String
  public var plainText: String?; public var formatTypes: [String]; public var contentHash: String
  public var pinned: Bool; public var lastCopiedAt: Date; public var sourceBundleID: String? }
@MainActor public final class ClipStore: ObservableObject {
  public init(directory: URL, now: @escaping () -> Date = Date.init)
  @Published public private(set) var clips: [Clip]
  public var historyLimit: Int                                  // trimming applied on add and on set
  @discardableResult public func add(_ d: ClipDraft) -> Clip     // dedupe by contentHash → update + move to top
  public func touch(_ id: UUID)                                   // lastCopiedAt = now
  public func setPinned(_ id: UUID, _ pinned: Bool)
  public func delete(_ id: UUID)
  public func updateText(_ id: UUID, _ text: String)              // becomes .text/.markdown/... via Classifier, formats = plain only, keeps lastCopiedAt
  public func clearHistory()                                      // removes unpinned only
  public func overflow(ifLimit: Int) -> Int                       // unpinned beyond limit
  public func list(_ tab: Tab, query: String) -> [Clip]           // newest first; pinned tab = pinned only
  public func data(for id: UUID) -> [String: Data]?               // nil if files missing
}
```
- Disk layout: `<dir>/index.json` (array of `Clip`), `<dir>/data/<uuid>/<n>.bin` with `formatTypes[n]` as the type. Write index atomically after every mutation.

### Task 3: Pasteboard read/write

**Files:**
- Create: `Sources/RecallCore/PasteboardIO.swift`, `Tests/RecallCoreTests/PasteboardIOTests.swift`

**Interfaces:**
- Consumes: `ClipDraft`, `Classifier`
- Produces:
```swift
public enum ReadResult: Equatable { case clip(ClipDraft), concealed, tooLarge, ownWrite, empty }
public enum PasteboardReader { static let maxBytes = 25 * 1024 * 1024
  static func read(_ pb: NSPasteboard, sourceBundleID: String?) -> ReadResult }
public enum PasteboardWriter { static let ownType = NSPasteboard.PasteboardType("app.recall.own")
  static func write(formats: [String: Data], plainOnly: Bool, to pb: NSPasteboard) }
```
- Read takes **every** type of the first item (and all file URLs across items, so several Finder files = one clip). Kind: file URLs → `.file`; image types (`public.png`, `public.tiff`) and no text → `.image`; `public.rtf`/`public.html` present → `.rich`; plain text → `Classifier`; else `.other`. `contentHash` = SHA-256 (CryptoKit) of the main content: plain text, else sorted file paths, else image bytes, else all bytes.
